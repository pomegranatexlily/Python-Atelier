Privacy & browser storage

POMEGRANATE × LILY · Updated October 13, 2026

Python Atelier is a browser-based Python learning and coding workspace. This page describes the site's current implementation, including essential storage and external services.

Information you save on your device

Your Python files, settings, practice records, challenge history, and optional brand image are saved in your browser's local storage. The site does not currently have accounts or an application server that receives those items. They remain in your browser unless you export or otherwise share them. Clearing site storage or using private browsing may remove them.

Shared-hostname storage limitation

Python Atelier currently shares the hostname pomegranatexlily.github.io with Freedom Arkives and potentially other projects. Browser local storage is scoped to the hostname, not to each GitHub Pages project path. Scripts that run under this same hostname can technically access stored information from other paths. Do not store passwords, financial information, or other highly sensitive data in the workbench. We plan separate origins before adding accounts or sensitive user information.

Cookies and optional tracking

We have not installed optional Google Analytics, advertising pixels, or behavioral profiling scripts. Our site provides a privacy-choice control that defaults optional analytics and marketing permission to off until you make a choice. We store your choice in the browser so we can remember it. Choosing to allow optional tracking does not activate a tracker because none is currently installed. We will seek new consent before introducing any new non-essential trackers.

Necessary browser storage supports your editor, file recovery, settings, and learning records. You can reject optional tracking and continue using Python Atelier.

Hosting and third-party technology

GitHub Pages hosts the website and, like other web hosts, may process standard connection information such as your IP address when serving pages. When the Python workbench starts, it downloads Python runtime files and editor scripts from jsDelivr, a third-party content delivery network. Those providers may process connection information under their own policies. Optional tracking choices do not disable requests required to serve the website or run Python.

After you make a privacy choice and start the workbench, the browser may register a service worker for cross-origin isolation and interactive Python input. This is a functional feature, not a marketing tracker. Python code and compatible packages that you choose to execute can also make their own network requests; review unfamiliar programs and packages before running them.

Changes and your choices

You can open the dialog at any time to change your optional tracking settings. You can also clear the site's data in browser settings; doing so may erase unsaved work, practice history, and consent preferences. Export a backup first.

Contact

For privacy questions or requests, reach the project maintainers through the Python Atelier GitHub repository. Issues are public; do not post sensitive personal information there.
